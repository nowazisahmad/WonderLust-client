## Project

Single Next.js 16.4.3 (App Router, Turbopack) site — no monorepo, no tests, no CI.

- Routes in `src/app/`: `/` (homepage sections) and `/add-destination` (stub). Root layout `src/app/layout.tsx` already wraps every page with `Navbar` + `Footer` — don't add them per page.
- Shared code: `src/components/` (`Navbar`, `Footer`, `homepage/*` are site components; `ui/*` are shadcn components). `@/*` maps to `./src/*`.

## Commands

```bash
npm run dev        # dev server at http://localhost:3000
npm run lint       # eslint (flat config: eslint.config.mjs)
npx tsc --noEmit   # typecheck — there is NO npm script for this
npm run build      # prod build; runs its own TypeScript check
```

- No test runner exists — don't invent test commands. Use npm: `package-lock.json` is the only lockfile (the README's yarn/pnpm/bun suggestions are boilerplate).
- Verify with `lint` → `tsc --noEmit` → `build`. All are slow here (1–5 min; even `eslint --version` took >3 min) — give commands generous timeouts, don't assume a hang.

## Gotchas

- The `AGENTS.md` block above is regenerated by `next dev` (source: `node_modules/next/dist/server/lib/generate-agent-files.js`). Keep the BEGIN/END markers intact; commit the block instead of reverting it.
- `tsconfig.json` type-checks generated files under `.next/types/` and `.next/dev/types/`. While `next dev` is running they can be mid-write, making `tsc` fail with bogus `TS1127`/`TS1128` errors in `.next/**` only. Fix: `npx next typegen`, then re-run `tsc`. Never edit `.next/` by hand.
- `npm run lint` has one pre-existing failure: `src/components/ui/carousel.tsx:98` (`react-hooks/set-state-in-effect`, shadcn-generated). It exits 1 even on an untouched tree — pass criterion is "no *new* errors"; don't rewrite the generated carousel to fix it.
- UI stack: Tailwind CSS **v4** — CSS-first config lives in `src/app/globals.css` (`@import "tailwindcss"`, `@theme inline`); there is no `tailwind.config`. shadcn style is **base-nova** on **Base UI** primitives (`@base-ui/react`), *not* Radix; icons are `@remixicon/react` / `lucide-react`. Add components with `npx shadcn add <name>` (config: `components.json`).
- `cn` comes from the `cn` npm package: existing code uses `import { cn } from "cn"`; `@/lib/utils` re-exports it. Either is fine.
- `next.config.ts` enables React Compiler (`reactCompiler: true`; lint enforces compiler-era rules like `react-hooks/set-state-in-effect`) and `cacheComponents: true` — with cacheComponents, uncached/dynamic reads (`cookies()`/`headers()`/uncached fetch) must sit inside a `<Suspense>` boundary or dev/build fails with a blocking-route error (see `node_modules/next/dist/docs/01-app/01-getting-started/08-caching.md`). Remote images are allowed only from `randomuser.me` — add hosts to `images.remotePatterns` in `next.config.ts`.
- `README.md` is stale create-next-app boilerplate (says Geist font; the app actually uses Josefin Sans). Trust config and code over it.
